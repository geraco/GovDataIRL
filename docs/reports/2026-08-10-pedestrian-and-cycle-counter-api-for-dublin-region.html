Pedestrian and Cycle counter API for Dublin Region

Dublin City Council cc-by · last updated 2025-06-19T18:31:50.405425

Pedestrian counters outnumber cycling-only counters by more than two to one across Dublin's monitoring network

  • Pedestrian-only sensors account for 47 of 131 counter records (36%), making them the dominant monitoring type in the network
  • Just 20 counters (15%) monitor cyclists only, while 19 counters track both pedestrians and cyclists together
  • Over one-third of counter records (34.35%) have missing location and setup information, indicating incomplete metadata in the API
  • The most common installation date was 27 February 2019, when 11 counters were set up, followed by 27 August 2020 with 9 installations
  • Geographic spread shows variation in placement: 28 of 131 longitude values (21.4%) are statistical outliers, suggesting some counters are positioned well outside the typical Dublin city centre cluster
A caveat worth knowing: Over one-third of records contain missing data across all fields, and the publisher notes existing data quality issues with specific sensors including Baggot Street Upper/Mespil Road/Bank
